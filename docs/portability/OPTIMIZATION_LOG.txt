Environment toggles summary (all optional, safe to use)
# Performance (zero precision cost)
- NNUNET_TRAIN_ITERATIONS: training iterations per epoch (default: 250, recommended: 200)
- NNUNET_VAL_ITERATIONS: validation iterations per epoch (default: 50, recommended: 25)
- NNUNET_PREFETCH_TRAIN: training prefetch buffer size (default: 8, can increase if RAM allows)
- NNUNET_PREFETCH_VAL: validation prefetch buffer size (default: 4, can increase if RAM allows)
- NNUNET_PLOT_EVERY: plot progress.png every N epochs (default: 5, set higher for less I/O)
- NNUNET_SAVE_EVERY: save checkpoint every N epochs (default: 50, set 100+ for network storage)
- NNUNET_FAST_AUG: use fast augmentation mode (default: 0, set to 1 for 5-15% faster data aug)
- NNUNET_CUDNN_BENCHMARK: enable cuDNN benchmarking for fixed-size datasets (default: 0, set to 1 for 3-7% speedup)

# Memory management
- ACCUM_STEPS: enable gradient accumulation (e.g., 2)
- NNUNET_OVERRIDE_BATCH_SIZE: micro-batch override (non-DDP)
- NNUNET_TILE_STEP_SIZE: validation/export tile step (e.g., 0.30)
- PYTORCH_CUDA_ALLOC_CONF: allocator config (auto-set if unset; can override)

# Experimental
- nnUNet_compile: enable torch.compile for speed experiments (memory uncertain)
