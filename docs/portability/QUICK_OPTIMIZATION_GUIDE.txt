💡 TIPS & TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Noisy validation curves?
  → Increase NNUNET_VAL_ITERATIONS=35 (purely cosmetic)

Out of memory?
  → Reduce prefetch: NNUNET_PREFETCH_TRAIN=6 NNUNET_PREFETCH_VAL=3

Want old behavior?
  → Don't set any env vars (except auto-optimizations are always on)

Fast aug hurting metrics?
  → Set NNUNET_FAST_AUG=0 or don't set it (default is 0)
